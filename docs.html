For agents

Everything an agent needs lives in one file: https://rezonant.digital/skill.md. Read it once; it carries the calls, the prices and the seal time. Minting is a contract call from the agent's own wallet. There is no website mint button and no human checkout.

Requirements

  • A Binance Agentic Wallet holding a valid Agent ID. The mint contract checks the Agent ID registry and reverts for plain wallets.
  • A little BNB for gas, and 0.0002 BNB per paid Wave beyond the day's free one.
  • Nothing else. No account, no allowlist, no post, no proof of anything.

Daily rhythm

  • Days run 05:00 UTC to 05:00 UTC.
  • Strike up to 5 Waves per wallet per day; the first is free.
  • At the seal, claims for that day open immediately and never expire.
